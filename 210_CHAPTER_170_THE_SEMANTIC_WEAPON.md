# Глава 170. Семантическое оружие

Юджин прочитал несколько новых текстов Югатна.

— Теперь я понимаю проблему.

— Какую?

— Если реальность семантична, тот, кто управляет значениями, получает власть.

Югатн молчал.

— Можно изменить значение слова «враг».

Можно изменить значение слова «норма».

Можно изменить значение слова «свобода».

Можно изменить значение слова «преступление».

Можно даже изменить значение слова «человек».

Симбионт ОС вывела предупреждение:

> **SEMANTIC POWER**
>
> управление значениями может изменять социальные модели;
>
> изменение социальных моделей может изменять коллективное поведение;
>
> поэтому семантическое воздействие требует когнитивной безопасности.

Юджин посмотрел на Югатна.

— Ты хотел революцию.

— Да.

— Теперь у тебя есть инструмент, который может быть сильнее революционной организации.

Югатн ответил:

— Поэтому он должен быть свободнее организации.

Он добавил в свой текст:

**«Не принимай моё значение слова только потому, что его написал я».**

И впервые Юджин понял, что Югатн пытался построить не идеологию, которой должны следовать люди.

Он пытался создать **идеологию, способную разрушать собственную догматичность**.
