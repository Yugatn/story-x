# Архитектура сюжета

## Сквозная дуга

Юджин → Трансцендент → имя Югатн → Садху → пандемия → проявление Югатна → революция → «Синема Катарсис» → Вьетнам → возвращение → Амбивалентный Солипсизм → Сюжет Икс → ИИ.

Это художественная последовательность. Отдельные события могут иметь разные уровни интерпретации.

## Метод

Каждое событие допускает четыре слоя: событие, переживание, интерпретация и модель.

Модель не равна субъекту и не равна реальности.

## Центральный конфликт

Югатн стремится понять происходящее, но обнаруживает, что любое объяснение меняет его отношение к происходящему.

Поэтому сюжет становится рекурсивным: наблюдение создаёт модель; модель меняет действие; действие меняет отношения; отношения создают новые наблюдения; новые наблюдения заставляют пересмотреть модель.

## Сюжетная задача

Финал не должен превращать все загадки в единственное объяснение. Развязка должна дать читателю несколько сильных моделей происходящего.
