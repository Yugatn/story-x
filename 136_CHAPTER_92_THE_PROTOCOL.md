# Глава 92. Протокол

Архив разведывательной подготовки оказался старше, чем предполагал Югатн.

В нём не было инструкции по созданию личности.

Были инструкции по адаптации.

Дыхание.

Пауза.

Контроль голоса.

Переключение внимания.

Изменение позы.

Использование разных речевых шаблонов.

Некоторые упражнения были обычной подготовкой.

Другие выглядели так, будто были предназначены для создания устойчивой социальной роли.

Симбионт ОС сравнила архив с наблюдениями Миры.

Совпадений стало больше.

Но вместе с ними выросло количество альтернативных объяснений.

Югатн прочитал итог.

> **OBSERVED:** совпадают отдельные элементы поведенческого протокола.
>
> **DERIVED:** обучение является правдоподобной гипотезой.
>
> **CLAIMED:** Мира является агентом внешней организации.
>
> **EVIDENCE:** отсутствует.
>
> **CONFLICTED:** часть признаков имеет естественные психологические объяснения.

Югатн закрыл архив.

— Значит, она шпион?

Симбионт ОС ответила:

— Нет.

— Почему?

— Потому что вопрос содержит вывод, которого нет в данных.

Югатн впервые услышал в голосе системы не осторожность.

А сопротивление.
