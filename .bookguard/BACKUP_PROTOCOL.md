# BookGuard — резервные копии двух книг

Статус: рабочий прототип; включение внешнего хранилища и обязательных CI-gates ещё не подтверждено.

## Обязательный цикл

1. Перед редактированием: проверить чистоту рабочего дерева; создать снимок `before` **за пределами репозитория**; проверить SHA-256 и тестовое восстановление.
2. После редактирования: создать отдельный снимок `after`, проверить SHA-256 и тестовое восстановление.
3. Сохранить **обе** копии в независимом постоянном хранилище с версионированием и ограничением прав на удаление; повторно скачать копию и проверить SHA-256 и восстановление.
4. Если любое условие не выполнено — остановить дальнейшие опасные изменения и указать `BACKUP_BLOCKED`.
5. Для Notion требуется **отдельный экспорт** страниц и вложений; Git-снимок не копирует Notion. Не утверждать полноту Notion без независимой сверки.

## Локальные команды (из корня Git-репозитория)

```bash
python3 scripts/bookguard_backup.py create --dest /absolute/external/path/before --label before
python3 scripts/bookguard_backup.py verify --dest /absolute/external/path/before
# Только после проверенной внешней копии — разрешённая редактура
python3 scripts/bookguard_backup.py create --dest /absolute/external/path/after --label after
python3 scripts/bookguard_backup.py verify --dest /absolute/external/path/after
```

Снимок включает **отслеживаемые Git файлы текущего рабочего дерева**, а не всю историю Git, не неотслеживаемые файлы, не Notion и не удалённые вложения. Для полного восстановления истории нужен отдельный `git bundle` и его проверка. Снимок не шифруется: использовать защищённое хранилище, особенно для приватных данных.

## Ограничения

Путь назначения не может находиться внутри репозитория; непустая папка запрещена во избежание перезаписи. Проверка восстановления производится во временную папку и сравнивает SHA-256 каждого файла. Успех локального теста **не доказывает** существование независимой удалённой копии. Для CI необходимо подключить внешнее хранилище и секреты с минимальными правами; до этого запрет считать защиту полной.
