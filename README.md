# Сюжет Икс

Это художественное произведение, а не научное доказательство.

> **Я есть. Ты есть. Я не отрицаю Тебя и твоего существования.**

## Центральный вопрос

**Что происходит с реальностью, когда наблюдатель понимает, что сам является частью наблюдаемой системы?**

Произведение исследует границу между субъектом и его моделью. Другой субъект не сводится к наблюдаемому профилю, памяти, телу, социальной роли или прогнозу.

## Художественное правило

Событие не равно его интерпретации.

Интерпретация не равна модели.

Модель не равна субъекту.

Модель не исчерпывает реальность.

Поэтому любое окончательное объяснение Икс остаётся частью повествования, а не абсолютной истиной.

**Сюжет Икс начинается там, где объяснение перестаёт быть достаточным.**
